# PERCIVAL · 线稿展廊｜视觉资产 v1.0

**实验性艺术杂志 × 赛博线稿展廊 × 成熟动漫拼贴。**

将已验收个人主页的整体风格、美术方向和设计参数整理成可复用资产。

## 使用顺序
1. 阅读 [完整规范](STYLE_GUIDE.md)，确认六项风格基因、配色、排版和美术边界。
2. 使用 [tokens.json](tokens.json) 与 [tokens.css](tokens.css) 作为新页面或新作品的设计基础。
3. 将 [PROMPTS.md](PROMPTS.md) 与本次内容交给设计师或AI，明确“沿用PERCIVAL · 线稿展廊v1.0”。
4. [asset-manifest.json](asset-manifest.json) 指向仓库中已确认的字标、图集、主图和字体许可证。
5. 克隆或下载**整个仓库**后打开本目录的 [index.html](index.html)，可查看离线视觉样本。保留相对目录；不要只下载HTML。移动目录后需调整字体与图片路径。

全局风格可复用；Lina和工具主图是各自项目内容，不能冒充其他产品截图。字体是已有子集，扩展文字需要核对缺字与授权。
本目录不包含个人照片、个人肖像、私人日记或账户配置，不是已安装的自动化skill。本次仅新增资产目录，线上主页内容不变。
