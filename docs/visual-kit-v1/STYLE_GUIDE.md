# PERCIVAL · 线稿展廊
## 视觉与美术资产规范 v1.0

归属：Percival 个人创作与展示体系。整理日期：2026-10-25。
基线：已验收个人主页，源提交 5bedb2b23afbfbc369ce9078930f199bbaa96fa1。
风格定义：**实验性艺术杂志 × 赛博线稿展廊 × 成熟动漫拼贴。**

这套语言服务于对个人经历和创作感兴趣的访客。视觉应有明确个性，内容应让人理解作者的经历、判断与作品。

### 六项识别基因
1. 黑与暖白建立基底，钴蓝建立识别，荧光黄形成焦点。
2. 每屏一个主要视觉中心，其余元素降低尺度、饱和度或对比。
3. 超大标题与小号注释形成尺度反差；标题可受控裁切，正文、按钮不可被裁切。
4. 暖白纸、黑油墨、荧光丝网印刷构成材质；撕纸、胶带、网点、错位叠印构成拼贴。
5. 走廊保持简单赛博线稿，近粗远细；墙面图形遵循透视，尽头保留一个符号焦点。
6. 人物采用成年、正常人体比例的动漫形象，保留个性；不使用Q版、迷你或大头娃娃比例。

### 色板
| Token | 色值 | 职责 |
|---|---|---|
| ink | #0A0A0C | 背景、轮廓与正文 |
| paper | #F3EDDF | 纸面、阅读与反白 |
| blue | #2B4CFF | 主识别与空间结构 |
| acid | #E8FF3A | 重点、动作入口与引导 |
| magenta | #FF2E86 | 局部冲突与章节点缀 |
| amber | #FFB020 | 温暖笔记意象 |
| teal | #00C2A8 | 局部物件与生态点缀 |

应用建议：一屏以黑/暖白和一种识别色构成主体；高饱和冲突色集中在约两处，底色约占六成。优先让丰富色彩进入主插画，外围排版维持克制。占比为复用建议，不是对每个现有页面的测量。
正文优先使用 ink/paper、paper/ink、paper/blue、ink/acid；每次仍检查实际对比度。

### 字体与排版
- 英文展示：Anton 400，用于项目名称、章节编号与英文大字。
- 中文标题：得意黑 Smiley Sans 400，用于标题与短句。
- 正文：系统无衬线，通常16–18px，行距1.7–2，阅读宽度54–68ch。
- 注释：系统等宽，通常9–12px；关键操作不可依赖过小字。
- 标题基线：clamp(56px,10vw,180px)，按设备与容器适配。
- 网点、纹理和交错线条退出正文区；正文采用纯色纸面或纯深色块。

仓库字体是网站已有子集；新文案可能缺字并回退系统字体。扩展时需补充子集或按许可证取得完整字体。两款字体各自的SIL OFL 1.1许可证保留于原素材目录。

### 版式与图形
页面最大宽度1600px，内容约1440px；侧边距clamp(22px,5vw,88px)，章节之间96–112px。
硬描边以3px/5px为主；硬投影基线8px 8px 0 ink；主要圆角为0；贴纸轻微旋转约±3°。
优先采用大海报、偏轴构图、大小图文对位、跨栏标题与边缘注册线。正文可去掉卡片框，避免整页相同卡片。
视觉叙事顺序：主焦点 → 内容说明 → 可达入口 → 辅助装饰。不要靠overflow:hidden掩盖内容溢出。

### 美术风格
成熟2D动漫/图像小说线条，粗细有层级，平涂光影，轮廓清晰。人物面部无遮挡；物件具有清楚的主形状。背景极繁通过叠层实现，细节向外围组织。
全局母题：神经花朵、轨道流星、独眼终端、手绘箭头。透明atlas为2×2，左上neural、右上orbit、左下terminal、右下arrow；每区3:2。使用CSS分区，不能将整图当成一个图标。

### 项目主图的边界
- After You：Lina概念肖像、记忆碎片、声音与纸张；按创作中展示。
- Bonnie Fridge：冰箱、食材、菜谱与购物便签，强调从照片到做饭的动作关系。
- TransFloat：悬浮窗口、光标、选区与译文层叠，强调理解的流动。
这些是项目专属概念插画，不能冒充软件实机截图。人物和项目内容应按授权与任务复用；全局可复用的是风格语言。
原始个人照片、个人动漫肖像、私人笔记和账户配置不属于本次视觉资产。

### 动效、交互与响应式
入场总时长≤2.2秒；门板约600ms；短反馈150–180ms。进入阅读后保持平静。
减少动态效果时停止位移、缩放、旋转，以≤200ms淡入兜底。装饰支持关闭；入口与正文保持可用。
装饰aria-hidden、pointer-events:none；内容主图有描述性alt。操作目标≥44×44px，具备清晰键盘焦点。
基线验收390/768/1440px，同时检查边界、可读性与键盘；手机显示优先保证内容顺序。

### 跨媒介复用
网页/社交项目主图推荐3:2，人物推荐4:5；文字单独排版，不在生图中烘焙正式标题。
印刷需将RGB转换到目标印刷流程后打样，特别核对荧光色。页面数值是屏幕基线，不是印刷尺寸。
